# CallShare

Plugin para BetterDiscord no Windows que prepara a conexão para abrir e transmitir telas pelos controles nativos do Discord. O túnel fica em espera durante a call e o CallShare pode voltar à conexão normal depois que a mídia começa.

## Instalação

1. Baixe o **ZIP completo** na [página da versão](https://github.com/matheus1g/CallShare/releases/tag/v0.15.2).
2. Extraia o ZIP. Copie `CallShare.plugin.js` e a pasta `CallShare-runtime` juntos para a pasta de plugins do BetterDiscord.
3. Ative o CallShare. No primeiro uso, abra **CallShare → Avançado → Instalar/atualizar auxiliar** e conclua o instalador do Windows.
4. Entre na call, aguarde **Em espera** e use o compartilhamento do Discord.

O pacote traz as instruções de instalação, os fontes e as licenças das dependências. A pasta `source` reúne os fontes de referência. Para instalar, use o ZIP da versão.
